1. Paper Geometry, Column Budget & Wrapping Rules

        

          
            

              Specification
              80mm Thermal Roll (Standard)
              58mm Thermal Roll (Compact)
            

          
          
            

              Printable Width / Font
              576 dots (72 mm) · Font A (12×24) · 48 columns
              384 dots (48 mm) · Font A (12×24) · 32 columns
            

            

              Item Table Columns
              ITEM (22, L) · 1sp · QTY (3, R) · 1sp · UNIT (10, R) · 1sp · TOTAL (10, R)
              ITEM (16, L) · 1sp · QTY (3, R) · 1sp · TOTAL (11, R); unit printed on indented sub-line (qty x unit)
            

            

              Line Clamp (Hard Cap)
              Max 2 lines per item name (1 primary + 1 continuation)
              Max 3 lines per item name (1 primary + up to 2 continuation)
            

            

              Wrapping & Hanging Indent
              Word-boundary wrap; continuation indented by prefix width (3 spaces for 1. , 4 for 10. ); numeric cols stay on Line 1
              Same word-boundary wrap and dynamic hanging indent; (qty x unit) prints directly below the last wrapped name line
            

            

              Truncation & Encoding
              Truncate final line to avail - 3 (strip trailing spaces/punctuation) + ASCII ...; normalize ₹ → Rs. and smart quotes to ASCII (CP437/858)
              Same ASCII ... truncation and unbroken SKU hyphenation (avail - 1 + -)
            

          
        

      


      

        
2. Section-by-Section Finalized Receipt Layout

        

          
            

              Section
              Fields Included
              Formatting & Constraints
            

          
          
            

              Store Header
              Logo (raster), Restaurant Name, Tagline, Address, Phone, GSTIN
              Centered; GSTIN is placed strictly in the header (not repeated in footer).
            

            

              Order Metadata
              Bill No., Date, Time, Order Type, Order No.
              Key-value aligned with : separator; Order No. follows <3-letter code>YYYYMMDD0001 (15 chars, bold). No Table/Token No.
            

            

              Items Table
              Numbered items, Qty, Unit Price, Line Total
              Separated by - above header and = below header; tabular right-aligned amounts.
            

            

              Tax & Totals
              SUBTOTAL, CGST (2.5%), SGST (2.5%), GRAND TOTAL
              Flat 5% GST split (2.5% + 2.5%) on top of subtotal; GRAND TOTAL framed by double = dividers.
            

            

              Bottom Footer
              Payment Mode, conditional Transaction ID (non-cash), dashed divider, THANK YOU, VISIT AGAIN!, Code 128 Order Barcode (HRI off)
              Print Transaction ID on 80mm (Txn ID on 58mm; wrap right-aligned if >24 chars) whenever Payment Mode is UPI, Card, or Other. Omit completely for Cash. No Customer Name and no GSTIN in footer.
            

            

              Feed & Paper Cut
              Feed 4 lines (ESC d 4) + Partial Cut (GS V 66 0)
              Clears 12–18 mm printhead-to-cutter offset; 58mm manual-tear printers ignore GS V safely while keeping the 4-line tear margin.
            

          
        

      


      

        
3. ESC/POS Command Mapping (Go 1.27.4 URQR-Bridge)

        

          
            

              Command
              Mnemonic
              Hex Bytes
              Go Byte Slice
              Purpose
            

          
          
            

              Initialize Printer
              ESC @
              1B 40
              []byte{0x1B, 0x40}
              Resets printer state before each receipt job.
            

            

              Align Left / Center / Right
              ESC a n
              1B 61 00/01/02
              []byte{0x1B, 0x61, 0x01}
              Centers header and closing block; resets to left for tables.
            

            

              Bold On / Off
              ESC E 1/0
              1B 45 01 / 00
              []byte{0x1B, 0x45, 0x01}
              Emphasizes store title, Order No., Grand Total, Payment Mode, and closing line.
            

            

              Select Font A (12×24)
              ESC M 0
              1B 4D 00
              []byte{0x1B, 0x4D, 0x00}
              Locks 48 columns on 80mm and 32 columns on 58mm.
            

            

              Code 128 Barcode (Order No.)
              GS h 50 · GS w 2 · GS H 0 · GS k 73
              1D 68 32 · 1D 77 02 · 1D 48 00 · 1D 6B 49 ...
              []byte{0x1D, 0x6B, 0x49, 0x11, 0x7B, 0x42, ...}
              Prints centered Code 128 barcode of Order No. directly below closing line with HRI text disabled (GS H 0) to avoid duplicating Order No.
            

            

              Feed 4 Lines
              ESC d 4
              1B 64 04
              []byte{0x1B, 0x64, 0x04}
              Feeds paper past cutter blade / tear bar before cutting.
            

            

              Partial Cut (Default)
              GS V 66 0
              1D 56 42 00
              []byte{0x1D, 0x56, 0x42, 0x00}
              Function B partial cut leaving a small center tab.
            

            

              Full Cut (Optional)
              GS V 65 0
              1D 56 41 00
              []byte{0x1D, 0x56, 0x41, 0x00}
              Function B full cut for kiosks or catch-tray setups.
            

            

              Legacy Partial Cut
              GS V 1
              1D 56 01
              []byte{0x1D, 0x56, 0x01}
              Fallback for older printers without Function B.
