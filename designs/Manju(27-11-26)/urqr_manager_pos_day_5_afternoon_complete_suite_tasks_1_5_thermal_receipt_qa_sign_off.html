        Rounding Rule Lock: Both PostgreSQL (NUMERIC(12,2)) and Go URQR-Bridge must use integer-paise half-away-from-zero ((subtotalPaise * 25 + 500) / 1000) instead of IEEE-754 floating-point float64 so odd subtotals (e.g., ₹149.00 → 372.5p → ₹3.73) never drift by 1 paise between DB and printed thermal paper.
      

    

  


  
  
  
  

    

      

        

          
Task 4 · Minor Line Spacing & Column Formatting Adjustments (Go ESC/POS)

          
Actionable patch list for Prajwal B N — Go 1.27.4 URQR-Bridge (receipt_template.go)

        

        
      


      

        

          
ADJ-01 · Explicit Font A Lock (ESC M 0)

          
Emit []byte{0x1B, 0x4D, 0x00} immediately after ESC @ so printers defaulted to Font B (64 cols) lock strictly to 48 cols (80mm) and 32 cols (58mm).

        

        

          
ADJ-02 · 80mm High-Value Column Guard (≥ Rs.10000.00)

          
Default 80mm budget (22 / 3 / 10 / 10) fits up to Rs.9999.99. Dynamically widen TOTAL to 11 cols (ITEM 21) if any line exceeds 999999 paise.

        

        

          
ADJ-03 · 58mm Code 128 Quiet-Zone Protection

          
On 58mm (384 dots), emit GS w 1 (0x1D, 0x77, 0x01) or Code 128 Subset C for the 12 numeric digits so quiet zones never clip the left/right edges.

        

        

          
ADJ-04 · Integer-Paise GST & Zero-Gap Cash Footer

          
Compute CGST/SGST via (subPaise*25 + 500) / 1000 and skip writing any newline for Transaction ID when PaymentMode == "Cash".

        

      


      
// urqr-bridge/internal/escpos/receipt_template.go — Day 5 Task 4 Adjustments
package escpos

var (
	CmdInit       = []byte{0x1B, 0x40}             // ESC @
	CmdFontA      = []byte{0x1B, 0x4D, 0x00}       // ADJ-01: Lock Font A (48/32 cols)
	CmdAlignLeft  = []byte{0x1B, 0x61, 0x00}       // ESC a 0
	CmdAlignCtr   = []byte{0x1B, 0x61, 0x01}       // ESC a 1
	CmdBoldOn     = []byte{0x1B, 0x45, 0x01}       // ESC E 1 (never GS ! double-width)
	CmdBoldOff    = []byte{0x1B, 0x45, 0x00}       // ESC E 0
	CmdFeed4      = []byte{0x1B, 0x64, 0x04}       // ESC d 4 (~14mm clearance)
	CmdPartialCut = []byte{0x1D, 0x56, 0x42, 0x00} // GS V 66 0 (Function B)
)

// ADJ-04: Integer-paise half-away-from-zero GST split (zero drift vs PostgreSQL)
func CalcGstPaise(subtotalPaise int64) (cgst, sgst, grand int64) {
	cgst = (subtotalPaise*25 + 500) / 1000
	sgst = (subtotalPaise*25 + 500) / 1000
	grand = subtotalPaise + cgst + sgst
	return
}

// ADJ-03: Width-safe Code 128 barcode (HRI disabled via GS H 0)
func BuildOrderBarcode(orderNo string, widthMm int) []byte {
	modWidth := byte(0x02) // 80mm (576 dots)
	if widthMm == 58 {
		modWidth = byte(0x01) // 58mm (384 dots) quiet-zone guard
	}
	payload := append([]byte{0x7B, 0x42}, []byte(orderNo)...) // Code 128 Subset B
	out := []byte{0x1D, 0x68, 0x32, 0x1D, 0x77, modWidth, 0x1D, 0x48, 0x00}
	out = append(out, 0x1D, 0x6B, 0x49, byte(len(payload)))
	return append(out, payload...)
}
